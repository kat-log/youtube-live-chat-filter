YouTube Special Comments Filter Settings

Settings for the extension that picks out special comments from YouTube live chat

API settings

Only needed for API mode. The default DOM mode works without an API key. You can switch modes from the popup settings (gear icon). Get an API key at Google Cloud Console

Language

The extension name and the toolbar tooltip always follow the browser language (a Chrome limitation). The popup switches the next time you open it.

Theme

When on, the popup uses the dark theme.

Comment time

Switches between the 12-hour and 24-hour clock. Example: ON 10:34 PM / OFF 22:34

When off, seconds are left out. Example: ON 22:34:56 / OFF 22:34

Debug mode

When enabled, detailed logs are written to the browser console. You can normally leave this off.

Auto start

When on, fetching starts automatically when you open a YouTube live stream. DOM mode starts without an API key; API mode does not start automatically until an API key is set.

How to use

  1. Open a YouTube live stream page.
  2. Click the extension icon to open the popup.
  3. If it does not start automatically, click "Start".
  4. You can show or hide streamer, moderator, member and regular comments separately.
  5. Only if you use API mode, set a YouTube Data API key above.

Comment types

Streamer Comments by the channel owner (the streamer)
Moderator Comments by moderators appointed by the streamer
Member Comments by channel members (sponsors)
Regular Comments by regular viewers

Getting an API key

  1. Open Google Cloud Console
  2. Create a new project or select an existing one
  3. Under "APIs & Services" → "Library", enable "YouTube Data API v3"
  4. Under "APIs & Services" → "Credentials", choose "Create credentials" → "API key"
  5. Copy the new API key and paste it into the field above

Note: Keep your API key safe and do not share it with anyone. Setting usage limits for the API is recommended.
